# AI Video Trends You Can Make From One Photo

The AI video trends going around TikTok and Instagram in 2026 that you can make from your own photo: no filming, no editing app, no prompt to write. Each one links to a ready-made template on [Turnly](https://turnphotointovideo.com) that turns your photo into that video.

**Which of these are still trending this week:** [AI video trends this week](https://turnphotointovideo.com/ai-video-trends/), re-counted from TikTok every Monday (how many different creators posted an AI version in the last 7 days).

## How trends get on this list

A trend is added once lots of people are posting AI versions of it on TikTok, and a template for it is live on Turnly. Trends that have died down stay listed (people still make them); the [weekly page](https://turnphotointovideo.com/ai-video-trends/) says which ones are still going. The AI Aging and Angel or Devil filters are evergreen: people post them all year.

Know a trend that's missing? [Open an issue](https://github.com/yining365/ai-video-trends/issues/new) with a link to a TikTok post.
